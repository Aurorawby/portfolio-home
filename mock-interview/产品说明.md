# 模拟面试官 · 产品说明（作品集版）

> 一句话：**粘贴 JD + 简历，离线生成一套针对性面试题**（岗位能力题 + 简历深挖题 + 通用题），
> 每题带考察点、答题框架和追问，可自评、可导出。

---

## 1. 为什么做

准备面试时最难受的三件事：

1. **不知道会被问什么**——JD 很抽象，刷通用面经又对不上；
2. **答案准备好了，追问接不住**——面试官一句"具体点"就露馅；
3. **复盘靠回忆**——面完就忘，下次还犯。

现有的模拟面试产品大多是通用题库、要付费、还要上传简历；而求职者最敏感的就是简历和 JD。

## 2. 我做成了什么

| 输入 | 处理（纯前端规则） | 输出 |
|---|---|---|
| 目标岗位 JD | 31 项能力题库匹配（同义词 + 命中次数加权），取前 9 项 | 岗位能力题（每题带考察点/框架/追问） |
| 我的简历 | 挑"像成果"的句子 + 与 JD 能力相关的句子 | 简历深挖题（"你简历里写到「…」，具体讲讲"） |
| — | 固定补自我介绍/动机/短板/反问 | 通用题 |
| 可选 | 自带 Key 调模型改写（BYOK） | 更自然、更贴个人经历的问法 + 追问 |

每题可 1-5 自评 + 写回答要点，一键导出 Markdown 带去面试。

## 3. 评测证据（可复现）

| 指标 | 数值 |
|---|---|
| 核心能力覆盖率 | **74.1%**（8 组真实 JD+简历，人工标注） |
| 简历引用率 | **100%**（8/8 都生成了引用简历原句的深挖题） |
| 追问完整度 | **100%**（每题都带追问） |
| 平均题数 | 12.6 道/套（可"补 3 道"扩展） |

复现：`node eval/mock-interview/run.mjs`（不调用模型）。报告：`eval/mock-interview/REPORT.md`。

**没做的**：问题本身的"质量分"（需要真实面试官评分）。所以**不宣称题库质量高**，
只报告覆盖与完整度——这是我在这套作品集里一直坚持的口径。

## 4. 关键取舍

1. **规则默认、模型可选**：隐私、零成本、可复现；不填 Key 也能拿到 80% 的价值；
2. **12-15 道而不是 50 道**：准备不完的题单等于没有；"补 3 道"做成按钮；
3. **每题固定带追问**：追问才是面试真正拉开差距的地方；
4. **引用简历原句而不是模型改写**：避免模型编造候选人没写过的经历。

## 5. 边界

- 题库 31 项，新措辞/新能力词会漏（页面会提示"未覆盖能力"）；
- 引用简历原句可能断章取义，要自己判断；
- AI 增强会把简历内容发给模型服务商（页面明确提示，Key 只存本机）；
- 生成的是"可能被问到的问题"，不是真题。

## 6. 如果继续做

- 题库扩到 60 项 + 难度分层（一面/二面/HR 面）；
- 加"回答质量规则评分"（结构完整性、有没有数字、有没有复盘），不依赖模型；
- 与面试复盘器打通：真实面试题一键导入复盘。
