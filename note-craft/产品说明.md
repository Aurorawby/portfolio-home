# 笔记工坊 · 产品说明（作品集版）

> 一句话：**AI 按爆款结构起草小红书笔记（3 标题 + 正文 + 标签），写完自动过「违禁词体检」——极限词 / 功效宣称 / 引流话术 / 限流词四类风险逐个高亮并给合规改法。**

---

## 1. 为什么做

我做过两年内容运营，深知新博主的死法：AI 直出的初稿里全是「全网最好用」「私信我领取」——
极限词踩广告法，引流话术踩平台红线，**被限流了都不知道自己哪里错了**。
市面工具只管生成不管审查，「生成」和「合规」断在半路。

解法是把三层拆开：**AI 初稿（有结构地写）→ 机器体检（词典扫风险）→ 人工终审（最后判断）**。
审查必须独立于生成——自己查自己不可信，这是这条产品线一贯的原则。

## 2. 我做成了什么

| 模块 | 实现 |
|---|---|
| 违禁词体检 | 4 类风险词典（广告法极限词 / 功效医疗宣称 / 诱导引流 / 限流词），词组级匹配 + 按风险等级排序 + 每类给「为什么 + 怎么改」，纯离线 |
| 字数检查 | 标题 ≤20 字 / 正文 ≤1000 字（平台限制），实时红绿 |
| AI 起草 | BYOK 按主题 / 类型 / 人群 / 语气生成 3 个备选标题（每个自带体检结果）+ 分段正文 + 标签；prompt 内嵌合规要求 |
| 结构模板库 | 种草测评 / 避坑经验 / 教程干货 / 清单合集 / 情绪共鸣，5 种结构可见可学（AI 起草用的就是它们） |
| 草稿台 | 标题点选、正文可编辑、一键复制分段输出 |
| 演示笔记 | 故意埋入极限词 + 引流话术的真实风格笔记——第一眼就看到体检器的价值 |

## 3. 评测证据（可复现）

`node eval/note-craft/run.mjs`（不调用模型、不依赖浏览器），19 条人工标注样本（违禁 10 / 干净 9）：

| 指标 | 数值 |
|---|---|
| 违禁词召回（标注的 11 处风险词） | **100%** |
| 干净样本误报率（含「第一次」「最近」等易误伤表达） | **0%** |
| 演示笔记体检 | 命中 4 处（全网最 / 第一名 / 绝对 / 私信我）全部带建议 |

**没做的**：平台完整限流清单（官方从未公开，词典只能覆盖社区验证过的常见词）；
第二标注人（n=19 且与词典设计同源，报告里已声明）。词典策略刻意「宁少抓、不误伤」——
误报摧毁信任，漏报还有人工终审兜底。

## 4. 关键取舍

1. **词典体检而不是模型体检**：可复现、可测试、零成本、每条命中可解释；
2. **词组级匹配**：单字词（如「最」）误伤「第一次」「最近」，牺牲少量召回换零误报；
3. **给合规改法而不是谐音梗**：建议永远是「改成主观表达 / 删功效宣称 / 换平台允许话术」，
   不教用户绕过审核——那是把用户往封号路上送；
4. **AI 要求合规 + 机器独立复查**：两层防线，prompt 靠不住的时候词典兜底。

## 5. 边界

- 词典覆盖常见风险词，永远有漏——**体检通过 ≠ 平台不判违规**，发布前人工判断是最后一道关；
- 「限流风险词」依据社区经验而非官方文档；
- 换设备 / 清浏览器数据丢 AI 配置；
- AI 起草基于文字描述，不了解你的真实产品，事实性内容（价格 / 成分）必须人工核对。

## 6. 如果继续做

- 自定义词典（用户加自己行业的风险词，本地生效）；
- 与「选题雷达」打通：选题 → 起草 → 体检一条线；
- 5 人使用访谈验证「5 分钟出可发布草稿」。
