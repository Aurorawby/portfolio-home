# 笔记工坊 NoteCraft · PRD

> 版本 v1.0 ｜ 2026-11-03 ｜ 作者：Aurorawby（AI 结对编程）
> 一句话：**给小红书博主的写作工坊——AI 按爆款结构起草笔记，机器体检违禁词与字数，人做最终判断。**

---

## 1. 背景与问题

小红书博主写作的三块真实摩擦：

- **不会起结构**：想写种草却写成流水账，爆款笔记其实有稳定结构（痛点开场 → 分点体验 → 真诚缺点 → 人群总结），但没人告诉你；
- **AI 直出的合规风险**：大模型随手就写「全网最好用」「治好了我的xx」「私信我领取」——极限词踩广告法、功效宣称没资质、引流话术直接违规，**新号被限流了都不知道为什么**；
- **市面工具只管生成不管审查**：生成器吐完就结束，合规全靠博主自己背。

**机会**：把「AI 起草」和「机器体检」串成一道工序——AI 按结构模板写初稿，写完立刻过违禁词词典，
风险词逐个高亮 + 给替换建议。**AI 初稿 + 机器审查 + 人工终审**，三层各干各的。

## 2. 目标用户与场景

| 谁 | 场景 | 频率 |
|---|---|---|
| 小红书新博主（粉丝 <1k） | 想写一篇种草 / 避坑：填主题 → AI 起草 → 改一改 → 体检通过 → 发布 | 每周 1-3 篇 |
| 老博主 | 自己写完丢进体检器扫一遍极限词（AI 帮不上，词典帮得上） | 随手 |
| 接商单的博主 | 商单文案风险自查（广告法极限词是实打实的法律风险） | 每单 |

## 3. 产品目标与指标

**北极星**：从「想写」到「拿到可发布草稿」≤ 5 分钟（填设定 30 秒 + 生成 40 秒 + 修改 3 分钟）。
**正确性护栏（可测试）**：违禁词召回 100%（标注样本）、干净样本误报 0。
**信任指标**（M2）：用户访谈——能说出「为什么这个词有风险」的比例 ≥ 70%（体检报告的可读性）。

## 4. 需求清单

| 级别 | 需求 | 验收标准（可测试） |
|---|---|---|
| P0 | 违禁词体检：4 类风险词典（极限词 / 功效宣称 / 诱导引流 / 限流词）+ 逐条替换建议 | 标注违禁样本召回 100%；干净样本（含「第一次」「最近」等易误伤表达）误报 0；结果按风险等级排序 |
| P0 | 字数检查：标题 ≤20 字、正文 ≤1000 字（平台限制） | 实时统计并红绿提示 |
| P0 | 结构模板库：5 种爆款笔记结构可见可学 | 每种含步骤清单 + 1 条实操 tip |
| P0 | 演示笔记：含故意埋入的违禁词 | 装载后体检报告立即命中 ≥3 处并给建议 |
| P1 | AI 起草：按主题 / 类型 / 人群 / 语气生成 3 标题 + 正文 + 标签 | 标题逐个带体检结果和字数；prompt 内嵌合规要求；JSON 容错 |
| P1 | 标题点选 + 草稿台可编辑 + 一键复制（标题/正文/标签） | 点选状态高亮；复制分段清晰 |
| P1 | 快速体检：单独粘贴任意句子扫风险 | Enter 直接触发 |
| P2 | 用户自定义词典（加自己行业的风险词） | 等有真实反馈再做 |
| P2 | 图片建议（每段配什么图） | 依赖图片理解，M2 评估 |

## 5. 明确不做（Not-doing）

- **不承诺「保证爆款」**：结构模板提高的是下限，不是流量保证；
- **不替代平台审核**：词典覆盖常见风险词但永远有漏，页面与报告都写明；
- **不做自动发布 / 多账号矩阵**：碰平台红线，不做；
- **不做违禁词的「绕过建议」**：给的是「合规改法」（改主观表达 / 删功效 / 换平台允许话术），不是教人规避审核的谐音梗——那是害用户。

## 6. 关键设计决策

1. **体检用词典而不是模型**：可复现、可测试（召回 / 误报可量化）、零成本、结果可解释；
   模型写稿时已被要求规避风险词，但「审查」必须独立于「生成」——自己查自己不可信；
2. **词组级词典而不是单字**：宁可少抓（漏掉「最」单字），不能误伤「第一次」「最近」——
   误报会摧毁用户信任，漏报只是少查一个（还有人工终审兜底）；
3. **替换建议讲「为什么」**：每类风险给一段人话建议（如极限词 → 改主观表达），而不是冷冰冰的「违禁」；
4. **演示稿故意埋雷**：演示笔记自带极限词和引流话术，第一眼就能看到体检器的真实价值。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 词典漏新话术 | 评测集随迭代扩充；报告写明「覆盖常见风险词，不替代平台审核」 |
| 词典误伤正常表达 | 词组级设计 + 误报测试（干净样本含「第一次」「最近」）；误报优先级高于召回 |
| AI 无视合规要求仍输出风险词 | 生成后自动体检兜底；标题逐个标风险 |
| 用户把「体检通过」当「保证没事」 | 页脚 + 报告双声明；「发布前人工判断永远是最后一道关」 |

## 9. 里程碑

- **M1（已完成，本版本）**：P0 全部 + P1 全部 + 评测（召回 100% / 误报 0）；
- **M2（有真实使用后）**：自定义词典、5 人使用访谈（北极星时长 + 体检可读性）、图片建议评估。

## 10. 本 PRD 的局限

- 违禁样本由作者本人标注（n=19），与词典设计同源，换人标注口径可能不同；
- 词典以小红书公开社区规范与广告法常识为据，平台规则随时更新，词典会滞后；
- 「限流风险词」的判定依据是社区经验而非平台官方文档（官方从未公开完整限流清单）。
