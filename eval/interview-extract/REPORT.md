# 面试复盘器 · 规则层抽取评测（开发集）

- 数据集：**开发集：规则迭代时看过，存在过拟合风险**，8 条用例 / 27 道标注题目
- 评测方式：把页面里的内联 JS 放进 Node 沙箱（DOM 桩）直接调用 `extractQuestions` / `classify`，不经过浏览器、不调用模型
- 匹配口径：中文 bigram 相似度 ≥ 0.5 视为同一道题，再人工抽查
- 迭代记录：初版召回 **85.2%** → 补充「无问号句」补召回规则 → 同一开发集 **100%**（因此必须看留出集，见 `REPORT-holdout.md`）

## 已知局限（诚实说明）

1. **这 8 条用例参与过规则调整，100% 不代表真实场景表现**——请以留出集 `REPORT-holdout.md` 为准；
2. 无问号陈述句现在靠「请求动词 / 疑问词 / 语气词」兜底，真实文本里可能误提陈述句（本次开发集没暴露）；
3. 超过 200 字的长问题会被过滤，复杂场景题可能整条丢失；
4. 分类靠关键词规则，题型标注本身有主观性；样例规模小，不做显著性结论。
