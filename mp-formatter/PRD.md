# 公众号排版器 MpFormatter · PRD

> 版本 v1.0 ｜ 2026-11-05 ｜ 作者：Aurorawby（AI 结对编程）
> 一句话：**公众号链路的最后一公里——Markdown 写稿，一键变成公众号后台可直接粘贴的内联样式 HTML，自带违禁词体检与字数提醒。解析与体检由代码完成，可复现。**

---

## 1. 背景与问题

公众号创作者写作链路的最后一步是「排版」：

- 公众号后台编辑器只认**内联样式**（不支持 class），Markdown 写完还要逐段手动调格式；
- 市面排版工具（mdnice 等）是「黑盒主题包」，不透明、不可控、有广告；
- 排版完没人查违禁词——极限词/引流话术在长文里更隐蔽，发出去才被限流。

**机会**：手写一个确定性 Markdown 解析器（约 60 行状态机），输出带 inline style 的 HTML；
违禁词词典与笔记工坊同源（一处维护的口径复用）。解析可测试、样式可完全掌控、体检可复现。

## 2. 目标用户与场景

| 谁 | 场景 | 频率 |
|---|---|---|
| 公众号博主 | Markdown 写完 → 粘进排版器 → 体检通过 → 富文本复制 → 后台 Ctrl+V | 每篇 |
| 我自己 | 作品集长文 / 面试复盘笔记排版 | 每周 |

## 3. 产品目标与指标

**北极星**：从 Markdown 到「可粘贴进后台」≤ 30 秒（输入即渲染，复制一步）。
**正确性护栏（可测试）**：Markdown → 块结构解析、内联样式渲染、违禁词命中与手工判定一致（确定性回归）。
**体验指标**：粘贴到公众号后台后样式保留率（标题色块/引用底色/字距）≥ 90%（人工核对，M2 记录）。

## 4. 需求清单

| 级别 | 需求 | 验收标准（可测试） |
|---|---|---|
| P0 | Markdown 解析：h1-h4 / 段落 / 无序·有序列表 / 引用 / 分割线 / **粗** *斜* `码` | 解析出的块序列与手工标注一致（回归评测） |
| P0 | 内联样式渲染：3 套主题（暖橙/黑白/蓝），全部 inline style | 输出 HTML 不含 class、含关键 inline style（回归断言） |
| P0 | 违禁词体检：3 类词典（与笔记工坊同源）+ 分类建议 | 命中与手工标注一致 |
| P0 | 字数统计：正文长度 + 800-3000 完读区间提示 | 计数与手工一致 |
| P0 | 富文本复制：ClipboardItem 写 text/html，公众号后台粘贴保留样式 | 不支持时降级为复制 HTML 源码并提示 |
| P1 | AI 导语：60 字内导语 | JSON 容错；结果插入建议而非自动改稿 |
| P1 | AI 备选标题：3 个 ≤20 字 | 同上 |
| P1 | 演示文章：故意含极限词，展示体检 | 装载即命中 |
| P2 | 图片占位符（提醒外链图会被拦截） | 已知边界，M2 做成显式占位 |
| P2 | 自定义主题色 | 等真实反馈 |

## 5. 明确不做（Not-doing）

- **不做外链图片直传**：微信拦截外链图，假装支持是坑用户——注释里明确「图片请后台传」；
- **不做 mdnice 式海量主题**：3 套克制的主题，排版的美感来自留白与层级；
- **不做自动发布**：不碰平台接口；
- **不用第三方 markdown 库**：手写解析器 60 行，换来确定性、可测试、零依赖（单文件产品的性格）。

## 6. 关键设计决策

1. **手写解析器而不是引库**：单文件零依赖是作品集产品的一致性格；解析规则透明（PRD 可列全），
   eval 可以断言块序列——黑盒库做不到；
2. **全部 inline style**：公众号编辑器不支持 class 选择器，inline 是唯一可靠路径；
3. **违禁词词典与笔记工坊同源**：同一份口径在两个产品复用，一处修两处益（并各自可测）；
4. **体检在渲染前**：改稿阶段就拦截风险词，而不是发布后挨限流。

## 7. 页面流程（低保真线框）

```
┌──────────────────┬──────────────────┐
│ Markdown 原稿     │ 公众号预览         │
│ textarea         │ （inline 样式）    │
│ [主题▾]          │                  │
│ [渲染+体检][演示]  │                  │
│ 状态行：字数+体检   │                  │
│ 违禁词报告区       │                  │
└──────────────────┴──────────────────┘
  [📋复制到公众号(富文本)] [复制HTML] [🧾AI导语] [🅰AI标题]
```

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 公众号编辑器对粘贴的兼容性 | 只用最保守 inline 属性（font/line-height/border/background/margin）；M2 记录保留率 |
| 手写解析器覆盖不全 | PRD 明确支持的语法集合（写进验收标准），未支持的行退化为段落（不丢内容） |
| 违禁词误报 | 词组级词典（同笔记工坊）；体检结果只提示不改稿 |
| 富文本复制兼容性 | ClipboardItem 不可用时降级复制源码 |

## 9. 里程碑

- **M1（已完成，本版本）**：P0 全部 + P1 全部 + 确定性回归评测；
- **M2**：粘贴保留率人工核对记录、自定义主题、图片占位符。

## 10. 本 PRD 的局限

- 解析器支持的 Markdown 子集有限（表格/代码块不支持，PRD 已列明）；
- 「粘贴保留率」需逐次人工核对，暂无自动验证手段；
- 词典覆盖常见风险词但不完整（同笔记工坊口径）。

## 竞品分析（2026-11-06 补充）

> 口径：基于公开产品能力的定性对比，未做付费/深度评测。

| 替代方案 | 它强在哪 | 在我们场景里的不足 | 我们的差异 |
|---|---|---|---|
| 秀米 / 135 编辑器 | 模板丰富、公众号生态成熟 | 依赖平台/登录，样式黑盒，难以讲清「为什么这样渲染」 | 单文件、手写解析器、内联样式可检查，不登录 |
| 壹伴 / 新媒体管家插件 | 与公众号后台集成好 | 需要装插件、绑定账号，规则不透明 | 不碰账号，Markdown→HTML 确定性转换 |
| Typora / Markdown 编辑器 | 写作体验好 | 导出公众号样式要手动调，容易丢样式 | 一键复制富文本 + 违禁词体检 + 字数提醒 |

**结论：** 不是编辑器，是「Markdown → 公众号可粘贴 HTML」的确定性小工具。
