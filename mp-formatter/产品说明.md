# 公众号排版器 · 产品说明（作品集版）

> 一句话：**Markdown 写稿 → 一键变成公众号后台可直接粘贴的内联样式 HTML——手写确定性解析器 + 同源违禁词词典 + 富文本复制，AI 只写导语和标题。**

---

## 1. 为什么做

公众号后台编辑器只认内联样式，Markdown 写完的最后一公里最烦人：市面工具是黑盒主题包，
而且没人帮你查「这篇长文里藏了几个极限词」。

我的解法：**手写 60 行确定性 Markdown 解析器**（不引库——单文件零依赖是这个作品集的性格），
输出带 inline style 的 HTML；违禁词词典与笔记工坊同源。解析可测试、样式完全可控、体检可复现。

## 2. 我做成了什么

| 模块 | 实现 |
|---|---|
| Markdown 解析 | 逐行状态机：h1-h4 / 段落 / 有序·无序列表 / 引用 / 分割线 / 粗斜体 / 行内码；未识别行退化为段落（不丢内容） |
| 内联样式渲染 | 3 套主题（暖橙/黑白/蓝），全部 inline style，公众号可粘贴 |
| 违禁词体检 | 3 类词典与笔记工坊同源，分类高亮 + 合规建议 |
| 字数提醒 | 800-3000 字完读区间红绿提示 |
| 富文本复制 | ClipboardItem 写 text/html + text/plain，降级复制源码 |
| AI（可选） | 60 字导语 + 3 个备选标题（JSON 容错） |
| 演示文章 | 故意含「最」类极限词，装载即见体检命中 |

## 3. 验证（可复现）

`node eval/mp-formatter/run.mjs`（不调用模型、不依赖浏览器）：

| 检查 | 结果 |
|---|---|
| Markdown 解析（块序列 + 文本） | 与手工标注一致 |
| 内联样式渲染（关键 style 片段存在、无 class） | 一致 |
| 违禁词命中 | 一致 |
| 字数统计 | 一致 |

## 4. 关键取舍

1. **手写解析器**：60 行换确定性、可测试、零依赖——eval 能断言「块序列」，引库做不到这种透明度；
2. **inline style 全量内联**：公众号不支持 class，这是唯一可靠路径；
3. **体检在渲染前**：改稿阶段拦截风险词，而不是发布后挨限流；
4. **不假装支持外链图**：微信拦截外链图，页面明示「图片请后台传」。

## 5. 边界

- Markdown 子集有限：表格、围栏代码块不支持（PRD 列明支持的语法）；
- 粘贴保留率依赖公众号编辑器行为，M2 逐次人工记录；
- 词典覆盖常见风险词但不完整，体检通过 ≠ 平台不判违规。
