# 图文工作室 · 产品说明（作品集版）

> 一句话：**5 种近期跑通的小红书爆款形态 schema 化（人设 Bot / 必看合集 / 必入榜 / 图文总结 / 对比测评），AI 按形态生成「封面 + 内页卡片 + 正文 + 标签 + 评论区运营脚本 + 发布策略」全脚本，规则层校验结构与违禁词，一键导出发布包——发布由人完成。**

---

## 1. 为什么做

「人设 Bot 帖」「养生必看」「必入榜 + 评论区整理链接」这些形态反复跑通，但它们的**结构约定**
（封面多少字、内页几页、评论区怎么运营）散落在创作者经验里；市面 AI 工具只生成正文，
而封面、内页、评论区才是爆款的主体。

以及一条必须先划清的线：**小红书禁止自动化发布**（无发布 API，模拟操作违反用户协议）。
所以这个产品的「全流程」终点是**发布包 100% 就绪**，最后一步永远由人完成——
深度做在形态 schema 和运营脚本上，不做平台红线下的事。

## 2. 我做成了什么

| 模块 | 实现 |
|---|---|
| 形态模板库 | 5 种爆款形态 schema 化：每种含封面字数区间 / 内页数量与厚度 / 正文字数 / 标签数 / 生成提示词 / 发布 checklist |
| AI 全脚本生成 | 按形态生成 cover / pages（每页标题+逐行要点）/ body / tags / **comments（作者置顶+预埋互动）** / **publish（时间+互动策略）** |
| 脚本编辑台 | 全部字段可改（内页可增删页），编辑实时触发重体检 |
| 校验引擎 | 7 项结构检查 + 违禁词全文扫描（与笔记工坊同源口径），完整性百分比 + issue 列表 |
| 发布包导出 | Markdown 一键复制：封面/内页/正文/标签/评论区/策略/体检/checklist |
| 精写示例 | bot 形态人工精写，装载即 100% 完整性（示例必须过自家体检） |

## 3. 验证（可复现）

`node eval/xhs-studio/run.mjs`（不调用模型、不依赖浏览器）：

| 检查 | 结果 |
|---|---|
| 精写示例（bot 形态）完整性 | 100%（7/7 结构检查 + 违禁词 0） |
| 缺页 / 封面超长 / 正文含违禁词 / 缺发布策略 | 各自触发对应 issue |
| 形态 schema 差异（bot vs must_see 的内页数量区间） | 校验正确区分 |

**诚实口径**：确定性回归测试；形态模板是「结构」沉淀，**不构成必爆保证**；
AI 生成内容的事实性由 checklist 强制人工核对。

## 4. 关键取舍

1. **评论区脚本是一等内容**：爆款的一半在评论区（扣 1 / 补链接 / 预埋神评）——这是市面工具的空白，
   也是本工具与「又一个生成器」的分界线；
2. **示例必须过自家体检**：自己 produce 的内容自己体检不过，工具没有公信力；
3. **自动发布是红线不是功能缺口**：以红 pill 常驻页面，PRD Not-doing 首条——
   「深入」的正确方向是脚本完成度与运营策略，不是碰平台规则；
4. **形态库是资产**：schema + 提示词 + checklist 都在代码里可见，每季度按真实爆款复盘更新。

## 5. 边界

- 不自动发布、不抓平台数据（红线）；
- 5 种形态是归纳不是穷尽，「必爆」不做保证；
- AI 生成可能编造案例细节，事实性核对是发布 checklist 的硬项；
- 违禁词覆盖常见风险词，体检通过 ≠ 平台不判违规；
- 「评论区预埋」属运营建议，尺度由用户自行判断。

## 6. 如果继续做

- 公众号深度形态扩展（深度长文结构 + mp-formatter 排版联动）；
- 内页图排版建议（文案 → 图片布局）；
- 与内容工作台联动：发布回流数据按形态分析「哪种形态在你的账号真的跑得动」。
