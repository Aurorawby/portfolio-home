# 图表解读器 ChartLens · PRD

> 版本 v1.0 ｜ 2026-11-03 ｜ 作者：Aurorawby（AI 结对编程）
> 一句话：**读论文 / 看报告的两件套——视觉模型按「结论 → 怎么读 → 该警惕」结构化读图；离线数字解读器算清「翻倍 vs +2pp」的基数陷阱。读图靠模型，算数靠代码。**

---

## 1. 背景与问题

看懂一张图表有三层门槛（对应痛点 P10）：

- **读不出来**：英文论文 / 业务报告的图，轴、图例、单位要看半天；
- **算不清醒**：「从 2% 涨到 4%」——翻倍（+100%）和 +2pp 两个说法都对，选哪个讲，多数人没概念；
- **防不了忽悠**：截断的 Y 轴、挑过的起止点、缺失的样本量——统计素养没人教。

现有方案：翻译软件不解释图；AI 聊天一次给一大段散文，没有「该警惕什么」的针对性；
统计课离实战太远。

**机会**：把「模型读图」和「代码算数」拆开——语义解读交给视觉模型（按固定结构输出），
数字计算与统计素养清单交给规则引擎（可测试、永远离线可用）。

## 2. 目标用户与场景

| 谁 | 场景 | 频率 |
|---|---|---|
| 学生 / 研究生 | 读论文截到一张图 → 上传 → 拿结构化解读 + 警惕点 | 每周 |
| 职场新人 | 看业务周报的图表 → 数字解读器核一遍汇报里的「翻倍」话术 | 每周 |
| 写报告的人 | 自己的图先自查一遍清单再交出去 | 每次写报告 |

## 3. 产品目标与指标

**北极星**：从「截图」到「拿到结构化解读」≤ 1 分钟。
**正确性护栏（可测试）**：数字解读（绝对差 / 相对变化 / 倍数）与陷阱提示触发，与手工计算完全一致（回归评测）。
**信任指标**：AI 读图的数字与原图一致（用户对照核对——页面持续提示，模型可能看错）。

## 4. 需求清单

| 级别 | 需求 | 验收标准（可测试） |
|---|---|---|
| P0 | 数字解读器：绝对差 / 相对变化 / 倍数三芯片 + 基数陷阱 / 小基数 / 大幅下降 / pp-vs-% 提示 | 计算值与提示触发与手工标注一致（回归评测） |
| P0 | 均值代表性检查：变异系数 CV + 样本量分级提示（n<10 / <30 / ≥30） | 计算与分级与手工标注一致 |
| P0 | 看图清单：5 种图类型 × 4 条统计素养检查项 | 内容静态确定，覆盖轴截断 / 样本量 / 相关因果 / 口径四类高频坑 |
| P1 | 图片解读（AI 视觉）：上传截图 → 四段结构化解读（摘要 / 怎么读 / 结论 / 警惕） | 默认智谱 glm-4v-flash（免费）；JSON 容错；失败给明确指引 |
| P1 | 演示解读：canned 留存曲线案例 | 无 Key 展示完整四段格式 |
| P2 | 多图对比解读 | 依赖更强视觉模型，M2 评估 |
| P2 | 自己的论文场景模板（方法节 / 结果节） | 等有真实反馈 |

## 5. 明确不做（Not-doing）

- **不做「AI 保证读对」**：视觉模型可能看错数字，页面持续提示对照原图；
- **不做统计检验计算器**（t 检验 / 卡方）：需要分布假设与教育解释，做不好反而误导，超出「解读器」定位；
- **不做批量论文解析**：一次一图，保持「针对性解读」的定位；
- **不做云存储**：图片只在浏览器内存中，解读完即弃。

## 6. 关键设计决策

1. **读图与算数分离**：视觉模型负责语义（它擅长），数字计算交给规则引擎（可测试、离线、永远正确）；
2. **四段固定结构**：摘要 → 怎么读 → 能支持的结论 → 该警惕什么——比散文式解读多出来的「警惕」段，
   正是统计素养教育的落点；
3. **基数陷阱做成产品功能**：「翻倍 vs +2pp」是职场汇报最高频的数字游戏，规则引擎自动识别
   （相对变化 ≥100% 且绝对差 ≤10）并给两种口径的写法建议；
4. **pp vs % 单独提示**：相差 1-2 个百分点时自动科普「百分点 ≠ %」——这是最常见的口径混淆。

## 7. 页面流程（低保真线框）

```
┌──────────────────────────────────────────┐
│ ① 图片解读：[选文件][🔍解读][🧪演示解读]    │
│    [图片预览]                             │
│    💡 摘要一句话                          │
│    📖 怎么读：轴/图例/单位…                │
│    📌 能支持的结论…                        │
│    ⚠️ 该警惕：轴截断/样本量/口径…          │
├──────────────────────────────────────────┤
│ ② 数字解读器：[A=2][B=4][单位▾][语境]      │
│    [+2 绝对] [+100% 相对] [2× 倍数]        │
│    ⚠️ 基数陷阱：两个数都给…                │
│    ———— 均值代表性 ————                   │
│    [均值][标准差][n] → CV + 分级提示       │
├──────────────────────────────────────────┤
│ ③ 看图清单：柱状图/折线图/饼图/散点图/表格   │
└──────────────────────────────────────────┘
```

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 视觉模型读错数字 | 页面持续提示「对照原图核对」；temperature 压低到 0.4 |
| 陷阱提示误触发（合法的翻倍） | 提示措辞是「建议两个数都给」而非「你错了」；阈值依据写在 PRD |
| 视觉模型免费档不可用 | 明确支持自定义 OpenAI 兼容接口；数字解读与清单完全不依赖 AI |
| 隐私（截图含敏感数据） | 图片不落盘、不经过中间服务器、解读完即弃，页面明示 |

## 9. 里程碑

- **M1（已完成，本版本）**：P0 全部 + P1 全部 + 数字引擎回归评测；
- **M2（有真实使用后）**：多图对比、论文场景模板、5 人使用访谈。

## 10. 本 PRD 的局限

- 陷阱识别阈值（相对 ≥100% 且绝对差 ≤10）是经验值，覆盖最高频场景，不能识别所有数字游戏；
- 看图清单是通用统计素养，不含领域特定检查（如医学图表的置信区间规范）；
- 视觉模型对中文截图的识别质量未做系统评测（M2 补 10 张标注截图的核对实验）。
