# 图表解读器 · 产品说明（作品集版）

> 一句话：**视觉模型按「结论 → 怎么读 → 能支持的结论 → 该警惕什么」四段结构化读图；离线数字解读器把「从 2% 涨到 4%」的翻倍话术算清楚。读图靠模型，算数靠代码。**

---

## 1. 为什么做

读论文和看业务报告时，图是信息密度最高也最容易被动手脚的部分：轴截断、挑起止点、
「翻倍」话术、相关当因果。AI 聊天能解释图，但给的是一大段散文，没有针对性的「该警惕什么」。

我的解法是把两层能力拆开：**语义解读交给视觉模型**（按固定四段结构输出，警惕段强制存在），
**数字计算交给规则引擎**（可测试、离线、永远算对）。

## 2. 我做成了什么

| 模块 | 实现 |
|---|---|
| 图片解读（AI） | 上传截图 → 视觉模型（智谱 glm-4v-flash 免费档 / 自定义）→ 四段结构化解读 JSON，容错解析 |
| 数字解读器 | 绝对差 / 相对变化 / 倍数三芯片 + 四类陷阱自动识别：基数陷阱（翻倍话术）、小基数波动、大幅下降归因、pp-vs-% 口径科普 |
| 均值代表性 | 变异系数 CV = 标准差/均值，>1 极端分散 / >0.5 偏散；样本量 n<10（只能当线索）/ <30（不稳健）分级提示 |
| 看图清单 | 柱状图 / 折线图 / 饼图 / 散点图 / 表格 × 每类 4 条统计素养检查项（轴截断、时间粒度、分母、口径…） |
| 演示解读 | canned 留存曲线案例，无 Key 看完整四段格式 |

## 3. 验证（可复现）

`node eval/chart-lens/run.mjs`（不调用模型、不依赖浏览器）：

| 检查 | 结果 |
|---|---|
| 数字计算（4 组输入的绝对差 / 相对变化 / 倍数） | 与手工计算逐字段一致 |
| 陷阱提示触发（基数陷阱 + pp 科普 / 常规文案 / 小基数） | 触发与手工判定一致 |
| 均值代表性（CV 分级 × 3 + 样本量分级 × 3） | 一致 |

**诚实口径**：确定性回归测试，保证数字引擎与手工计算一致。AI 读图部分**不做质量宣称**——
视觉模型可能看错数字，页面持续提示对照原图（这符合本作品集一贯的口径：能证明多少说多少）。

## 4. 关键取舍

1. **四段固定结构而不是自由问答**：「该警惕什么」被强制成为输出的一部分——统计素养教育落在产品结构里；
2. **陷阱自动识别而不是清单罗列**：规则引擎算出「翻倍 + 绝对差小」的组合才提示，比静态文章更有针对性；
3. **pp vs % 自动科普**：相差 1-2 个百分点时触发——最常见的口径混淆值得一个专属提示；
4. **图片不落盘**：只在浏览器内存中预览，解读请求直接发给服务商，本产品无后端。

## 5. 边界

- AI 读图可能看错数字，关键结论必须对照原图核对（页面持续提示）；
- 陷阱识别阈值是经验值，覆盖最高频场景，不承诺识别所有数字游戏；
- 看图清单是通用统计素养，不含领域特定规范（如医学图表）；
- 视觉解读需要支持图片的模型（智谱 glm-4v-flash 免费 / 自定义接口），纯文本模型不行——设置页已分开标注。

## 6. 如果继续做

- 10 张标注截图的读图核对实验，把「AI 读图质量」从「不宣称」升级为「有数据」；
- 多图对比解读（改版前后两张图并读）；
- 与「汇报一页纸」打通：解读结论直接生成一页纸的「数据」板块。
