# 3 人小规模试用：执行包

> 目的：发布后 3 天内拿到 **3 个真实用户**的反馈——不是"好不好玩"，而是：
> **能不能自己完成、卡在哪、有没有想再用的理由。**
>
> 5 人是经典下限；求职期时间紧，**先做 3 人拿方向**，比"等有空再做 5 人"强。
> 数据只填真实结果；示例数据（`timing_sheet.example.csv`）仅演示格式，**不要当真实结果写进简历**。

---

## 一、测什么（3 个任务，30-40 分钟/人）

| # | 任务 | 页面 | 观察点 |
|---|---|---|---|
| T0（可选） | 打开求职工作台，填 JD+简历，点「去扫描 JD」再回来 | `job-workbench/index.html` | 三步流程是否走得通、知不知道下一步该干嘛 |
| T1 | 粘贴 2 份真实 JD，说出「市场最需要哪 3 个能力」 | `jd-radar/index.html` | 能否独立完成分析；雷达图看不看得懂 |
| T2 | 粘贴一段自己真实的面经，提取题目并导出复盘 | `interview-review/index.html` | 提取是否准确；导出/保存是否顺畅 |
| T3 | 测一次 AI 产品经理测试，把结果分享给一个人 | Quiz Factory | 结果页是否想分享；有没有卡点 |

三个任务可以一次测完，也可以拆成 3 天各 10 分钟。

---

## 二、被试怎么找（3 人）

优先：正在找 AI 产品/AI 相关实习的同学 → 做过产品实习的同学 → 内容/运营转产品的同学。
**不要找**：和你一起做这个项目的人、完全不相关的朋友（反馈会失真）。

远程（共享屏幕）或当面都行，**让对方操作，你只看**。

---

## 三、主试怎么做

照 `facilitator_script.md` 念：开场 → 任务卡 → 中性提示（卡住 2 分钟才给）→ 结束访谈 3 问。
**不教操作、不解释设计、不评判。**

---

## 四、怎么记录

- 计时：`timing_sheet.csv`（Excel 打开），**不要事后回忆**；
- 每位被试复制一页 `record_template.md`（改成 P1/P2/P3）；
- 访谈至少记 2 句**原话**。

填完后：

```bash
node user-test-3/analyze.mjs user-test-3/timing_sheet.csv
```

会输出每个任务的完成率、平均耗时、卡点，并生成 `RESULTS.md`。

---

## 五、怎么用它写简历 / 面试

**只写真实数据**，例如：

> 3 人小规模试用：任务完成率 3/3，JD 雷达完成一份分析平均 X 分钟，主要卡点在 Y；
> 据此改了 Z。

面试话术：

> "我找了 3 个正在找 AI 产品实习的同学试用，最大的卡点不是功能，是**不知道要粘几份 JD**。
> 3 个人里 2 个人卡在同一处，所以我加了示例和默认引导——这是产品问题。"

---

## 六、诚实的边界

- 3 人是**方向性**反馈，不能做统计结论；简历写"3 人试用"，不写"验证有效"；
- 同学有"给面子"偏差，明确说"说难用是在帮我"；
- 样本偏向学生，和真实职场用户有差异，写清样本背景。
